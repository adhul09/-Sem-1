# Prompt Constraints: Output Format Control
 
You can tell the AI exactly what format you want the answer in, so it's easier to use directly (copy-paste into code, docs, etc.)
 
**Examples of format constraints:**
```
Give me only the code, no explanation.
```
```
Respond only in a JSON object, no extra text.
```
```
Give the answer as a numbered list of steps.
```
 
This is useful when you're pulling the answer straight into a file or script, and don't want to manually clean up extra text around it.
